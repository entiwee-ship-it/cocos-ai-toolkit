# Cocos AI Bridge

Cocos AI Bridge 是面向 Cocos Creator 3.8.x 的项目内编辑器扩展，为 Cocos AI Toolkit 提供编辑器状态、资源、节点、组件、Prefab、保存和 Preview 桥接能力。

| 项目 | 数据 |
| --- | --- |
| 当前版本 | V0.6.9 |
| 发布日期 | 2026-09-01 |
| 作者 | 李威-Enti |
| Creator 版本要求 | `>=3.8.0 <3.9.0` |
| 已验证 Creator 版本 | 3.8.8 |
| 支持平台 | Windows (`win32`) |

扩展通过项目 `extensions/cocos-ai-bridge` Junction 加载，与固定运行 Worktree 中的 MCP Server、Probe Server 和 Bridge 构建保持一致。
